## Rules

- Plans differ by **seats only**; every standard feature is in every plan. No feature tiers.
- Charged at signup with a **30-day money-back guarantee**. There is **no free trial**.
- A feature is advertised only if `getAdvertisableFeaturesForTemplate(<template>)` returns it. Hidden = never mentioned.
- Usage-priced items are described as usage-priced, with the price from the code below — never a made-up number.
- Competitor prices: only as fetched from the vendor's own site, with the date (docs/comparisons.json).
